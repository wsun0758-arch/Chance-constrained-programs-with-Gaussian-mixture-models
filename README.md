Chance constrained programs with Gaussian mixture models
Authors: Zhaolin Hu, Wenjie Sun, and Shushang Zhu
With this repository, you can reproduce the results of the paper by following these steps:
1) Test Problem file: Codes for solving (15a)-(15b) in the 4.1 A test problem
2) Value at Risk Portfolio Optimization Problem file: Codes for solving (17a)-(17c) in 4.2. A portfolio optimization problem
3) Mixed Integer Programming Formulation: Codes for solving (16a)-(16d) in the 4.1 A test problem
