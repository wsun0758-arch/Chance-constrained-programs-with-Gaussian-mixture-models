Chance constrained programs with Gaussian mixture models. IISE Transactions, 54(12), 1117–1130. https://doi.org/10.1080/24725854.2021.2001608

Authors: Zhaolin Hu, Wenjie Sun, and Shushang Zhu

With this repository, you can reproduce the results of the paper using following folders:

1) Test Problem folder: Codes for solving (15a)-(15b) in the 4.1 A test problem
   
2) Value at Risk Portfolio Optimization Problem folder: Codes for solving (17a)-(17c) in the 4.2. A portfolio optimization problem
   
3) Mixed Integer Programming Formulation folder: Codes for solving (16a)-(16d) in the 4.1 A test problem
